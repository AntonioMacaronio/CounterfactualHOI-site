# CounterfactualHOI — project website

Live site: https://antoniomacaronio.github.io/CounterfactualHOI-site/

Static GitHub Pages site with the project's progress: 4D hand–object reconstructions as interactive viser
viewers, in the order we tried them (Do-as-I-Do, Open-CHOIR, our FoundationPose + Depth Pro 2 pipeline and its
agentic refinement), the motions retargeted to the Sharpa hand, the robot embodiment (arm, hand, wrist camera),
the MiniMax H3 counterfactual videos and the first retargeting test.

Generated by `scripts/site/build_site.py` in the CounterfactualHOI code repo (branch `dev/antzhang`); do not edit
by hand. Every page also works offline: open `index.html`.
