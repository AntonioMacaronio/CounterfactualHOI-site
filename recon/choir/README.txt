Open-CHOIR 4D hand-object reconstructions of 10 real videos (CounterfactualHOI)

1. Unzip this folder (keep all files together).
2. Open index.html in Chrome, Edge, Firefox or Safari. No internet or server needed.

The page has two tabs, "pp" and "prp", each with the same five objects (small metal case, blue tape roll,
black spatula, gray mug, dish soap bottle). Each panel is an interactive 3D viewer: drag to orbit,
right-drag to pan, scroll to zoom, and use the playback bar at the bottom to play/pause or scrub.
Blue = reconstructed hand, orange = reconstructed object, colored points = the scene from the first frame,
plus the real camera with the current video frame. The scene is rotated so gravity points straight down.
Each viewer file (e.g. pp_anthony_real_1.html) also works on its own.
