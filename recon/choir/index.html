Open-CHOIR 4D hand–object reconstructions of the real videos

One tab per recording set; the same five objects in each (small metal case, blue tape roll, black spatula, gray mug, dish soap bottle). Each viewer shows CHOIR's final contact-optimized MANO hand (blue) and SAM3D object (orange), the frame-0 depth points of the scene (hand/object pixels removed) and the real camera's frustum with the current video frame. The scene is rotated so GeoCalib's gravity points down (grid = table height); the depth points are rescaled so the object rests on the table in the first frame, so where it ends up relative to the table at the end shows CHOIR's depth drift. Drag to orbit, scroll to zoom; the playback bar is at the bottom of each viewer.
