FoundationPose + Depth Pro 2 4D hand–object reconstructions of the real videos

One tab per recording set; the same five objects in each (small metal case, blue tape roll, black spatula, gray mug, dish soap bottle). Pipeline: Depth Pro 2 metric video depth, scaled so it agrees with the Dyn-HaMR MANO hand (the hand's known size is the metric reference); per-frame SAM3 masks of the object and hand (text prompts); the object's textured SAM3D mesh (from the first frame), sized and tracked through the video by FoundationPose on that depth; the hand moved per frame onto the depth map. Each viewer shows the hand (blue), the textured object, the frame-0 depth points of the scene (hand/object pixels removed) and the real camera's frustum with the current video frame. Hand, object and table come from the same metric depth; the scene is rotated so GeoCalib's gravity points down (grid = table height). "QC frames" shows 12 video frames per clip with the tracked object rendered (orange), its SAM3 mask (green) and the hand (blue). Drag to orbit, scroll to zoom; the playback bar is at the bottom of each viewer.
