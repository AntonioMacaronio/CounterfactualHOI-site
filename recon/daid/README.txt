Do-as-I-Do 4D hand-object-table reconstructions (CounterfactualHOI, IMG_5710)

1. Unzip this folder (keep all files together).
2. Open index.html in Chrome, Edge, Firefox or Safari. No internet or server needed.

Each panel is an interactive 3D viewer: drag to orbit, right-drag to pan, scroll to zoom,
and use the playback bar at the bottom to play/pause or scrub. Each viewer file
(real.html, apple.html, wood_block.html, lemon.html) also works on its own.
